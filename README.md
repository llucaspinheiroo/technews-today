# README – Desafio TechNews

## Descrição
Atividade de criação de um portal de tecnologia utilizando HTML e CSS, com foco em organização, estilização e responsividade.

## Tecnologias
- HTML5
- CSS3

## Recursos
- Cabeçalho estilizado
- Artigo de destaque
- Vídeo incorporado
- Formulário de newsletter
- Efeitos de hover
- Layout responsivo

## Arquivos
- `index.html`
- `10a_desafio.css`

## Objetivo
Aplicar conhecimentos de HTML semântico e CSS na criação de uma página moderna e responsiva.
